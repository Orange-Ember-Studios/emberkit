# Icons

`@emberkit/icons` is a lightweight, tree-shakeable SVG icon library built for EmberKit.

## Installation

```bash
pnpm add @emberkit/icons
```

## Basic Usage

```tsx
import { IconSearch, IconMenu, IconX } from '@emberkit/icons';

function Header() {
  return (
    <header>
      <IconMenu size={24} />
      <IconSearch size={20} />
      <IconX size={16} />
    </header>
  );
}
```
